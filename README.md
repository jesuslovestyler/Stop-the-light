# Stop the Light

A free timing game you play in your browser: a light races back and forth — stop it dead on the mark. Simple, quick, and harder than it looks.

**Live:** https://jesuslovestyler.github.io/Stop-the-light/
**Home:** https://jesuslovestyler.com/
